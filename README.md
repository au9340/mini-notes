# mini-notes

一个**只为看 UI**的极简记事本 demo。单文件 HTML，零依赖，双击就能用。

## 怎么打开

- 直接下载 `index.html`，双击用浏览器打开；或
- 在线预览：仓库 Settings → Pages → Source 选 **GitHub Actions**，等 workflow 跑完，访问 `https://au9340.github.io/mini-notes/`

手机上打开同一页面，`添加到主屏幕` 后基本等同于一个 App。

## 功能范围（就这么点）

- 新建 / 编辑 / 删除
- 自动保存（停止输入 300ms 后写入 localStorage）
- 自动跟随系统浅色 / 深色
- 桌面端双栏，手机端单栏
- 快捷键 `N` 新建

**刻意没做**：账号、同步、分类、标签、搜索、富文本、设置页、导出。

## 设计取舍

| 决定 | 原因 |
|---|---|
| 侧栏只有「Notes」和一个 `+` | 没有标题栏、没有工具栏、没有菜单 |
| 列表项无边框，靠 hover 底色区分 | 减少视觉噪音 |
| 编辑区是**裸 textarea**，无边框、无工具栏 | 打开就写，一行 chrome 都不留 |
| textarea 自动增高，随内容撑满页面 | 长笔记不用内部滚动条 |
| 删除按钮 hover 才出现 | 平时不占注意力 |
| 无「保存」按钮 | 自动保存，没有状态要给用户看 |
| 字体用系统栈，行高 1.8 | 中文长文可读性优先 |
| 内容 600px 居中 | 一行不超过 ~35 个汉字，接近纸质阅读宽度 |

## 已知取舍

- 数据在 `localStorage` 里，**清浏览器数据会丢**。所以这个 demo 的定位是「看 UI」，不是「正式用」。
- 如果要正式用：把存储换成「一条笔记一个 `.md` 文件 + 同步文件夹」，代码改动不大，但备份/同步/导出/跨端全部白送，不用再写任何功能。
